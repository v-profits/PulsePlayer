# Pulse Player

Офлайн-плеер для Android: ваша музыка, плейлисты, избранное и эквалайзер. Без рекламы и без интернета.

## Возможности

**Воспроизведение**
- Форматы: MP3, FLAC, WAV, OGG, Opus, AAC, M4A, MKA, AMR, MIDI и другие, которые поддерживает Android
- Hi-res вывод, воспроизведение без пауз между треками (gapless)
- Работа в фоне, управление из шторки уведомлений, с экрана блокировки и из Bluetooth-гарнитуры
- Автопауза при отключении наушников
- Перемотка: ведите пальцем по полоске прогресса (в мини-плеере и на экране «Сейчас играет»)
- Скорость от 0.5x до 2x, shuffle, повтор (всё / один трек), таймер сна
- Очередь: перемещение и удаление треков
- Приложение работает только в портретной ориентации (экран не поворачивается)
- Над списками закреплена одна кнопка «Играть»: она играет именно открытый список (вкладка, папка, альбом, исполнитель, плейлист). Перемешать и повтор — в мини-плеере; при включённом «перемешать» любой запуск (в том числе папки) начинается со случайного трека. Настройки → «Открывать плеер при Play» (по умолчанию выключено) открывает полный экран плеера
- Мини-плеер (всегда виден): плей/пауза, стоп, предыдущий/следующий, перемешать, повтор, избранное, в плейлист, открыть на весь экран. Включённые кнопки залиты цветом, выключенные приглушены, недоступные бледные
- «Стоп» останавливает полностью и очищает очередь; «Плей» после стопа начинает с первого трека открытой вкладки или списка

**Библиотека**
- Вкладки: Треки, Альбомы, Исполнители, Папки, Плейлисты, Файлы
- Разделение «Все / Музыка / Книги»: книги — аудиокниги, подкасты и треки длиннее порога из настроек
- Внутри папки или плейлиста в верхней панели есть поиск, сортировка, эквалайзер и настройки
- Поиск (в том числе голосом) и сортировка, в том числе «по имени файла»
- Умный порядок номеров: файлы 1, 2, 3 … 10, 11, 12 идут по порядку, а не 1, 10, 11, 12, 2
- В каждой строке трека сердечко (избранное) и значок плейлиста; они меняют вид, когда трек добавлен
- В «Избранном» и в каждом плейлисте есть кнопка «Очистить список»
- Вкладка «Файлы»: выбор отдельных файлов или целых папок (в том числе на SD-карте) через системный диалог
- Открытие аудио из других приложений через «Открыть с помощью»
- «О треке» (три точки у трека): имя файла, формат, расположение в иерархии папок, размер, битрейт, теги
- Встроенная инструкция (Настройки → Инструкция)
- Окно оценки: на 10-м запуске и далее каждые 50, пока приложение не оценено. 4–5 звёзд ведут в RuStore, 1–3 открывают письмо разработчику

**Выбор нескольких элементов**
- Долгое нажатие на трек, альбом, исполнителя или папку включает режим выбора
- Дальше — одно нажатие добавляет к выбору. Выбирать можно сразу несколько папок и играть их содержимое, не открывая
- Выбранные элементы подсвечены цветной плашкой и галочкой в кружке, невыбранные отмечены пустым кружком
- Действия: играть, играть следующим, в очередь, в плейлист, в избранное, играть выбранные по кругу

**Эквалайзер**
- 12 полос (±12 дБ), пресеты, предусиление, бас, высокие, стереобаза, баланс, объёмный звук, усиление громкости
- Двойное касание полосы — в ноль, нажатие на значение — сброс параметра

**Настройки**
- Тема: системная / светлая / тёмная
- Язык: системный / English / Русский
- Скрытие слишком коротких треков, «не гасить экран» на экране плеера

## Как пользоваться

| Что сделать | Как |
|---|---|
| Выбрать несколько треков | Долгое нажатие на трек, затем нажимайте на остальные |
| Выбрать несколько папок | Вкладка «Папки» (или «Файлы»), долгое нажатие на папку, затем на остальные |
| Добавить в плейлист / избранное | Выберите элементы, затем иконка плейлиста или меню ⋮ вверху |
| Перемотать трек | Ведите пальцем по полоске прогресса |
| Голосовой ввод | Значок микрофона в поле: текст добавляется к уже введённому, с заглавной буквы в начале и после . ? ! |
| Очистить поле | Крестик в поле ввода |
| Сменить тему или язык | Значок шестерёнки на главном экране |

## Разрешения

- **Музыка и аудио**: чтобы показывать вашу библиотеку. Без него работает вкладка «Файлы».
- **Уведомления**: для управления плеером из шторки.
- Голосовой ввод использует системное распознавание речи Google; отдельное разрешение на микрофон приложению не нужно.

## Если что-то не работает

- **Музыка не появилась**: проверьте разрешение, затем Настройки → «Обновить библиотеку». Проверьте, не включено ли скрытие коротких треков.
- **Не играет файл**: внизу появится сообщение; неподдерживаемые форматы (например, WMA, APE) плеер пропускает сам. Реальный формат файла виден в «О треке».
- **Эквалайзер без эффекта**: если аудиотракт устройства не поддерживает обработку, плеер автоматически переключается на обычный режим без эквалайзера.
- **Голосовой ввод не отвечает**: на устройстве должно быть установлено приложение распознавания речи (например, Google).

## Сборка

1. Android Studio (Koala 2024.1 или новее), JDK 17 (встроенный).
2. File → Open → папка проекта, дождитесь Gradle Sync.
3. Run ▶ на устройстве или эмуляторе (Android 8.0+, API 26).

Пакет и applicationId: `com.semenenko.pulseplayer`.

Стек: Kotlin, Jetpack Compose (Material 3), Media3 (ExoPlayer + MediaSession), Room, Coil.

## English

Pulse Player is an offline Android music player: library by tracks/albums/artists/folders, multi-select
(tracks and whole folders) with playlists and favorites, a 12-band equalizer with effects, drag-to-seek progress
bars, voice input for text fields, system/light/dark theme and English/Russian language.
Build with Android Studio (JDK 17, Android 8.0+).
