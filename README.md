# Pulse Player

Музыкальный плеер для Android на Kotlin + Jetpack Compose (Material 3) + Media3 (ExoPlayer).

## Как открыть
1. Android Studio (Koala 2024.1+ / Ladybug) → **File → Open** → папка `PulsePlayer`.
2. Дождаться Gradle Sync (JDK 17 — встроенный в Android Studio). Gradle 8.9 скачается автоматически.
3. Run ▶ на устройстве/эмуляторе (Android 8.0+, API 26).

## Возможности
- Все форматы, которые поддерживает Android/Media3: MP3, FLAC, WAV, OGG, Opus, AAC, M4A, MKA, AMR, MIDI и др.
- Hi-res вывод (float PCM), gapless, автофокус, пауза при отключении наушников
- Фоновое воспроизведение, уведомление, экран блокировки, Bluetooth/гарнитура (MediaSession)
- Библиотека: Треки / Альбомы / Исполнители / Папки, поиск, сортировка
- Вкладка «Файлы»: выбор нескольких файлов или целой папки через системный диалог
- Мультивыбор (долгое нажатие): играть, следующим, в очередь, в плейлист
- Плейлисты, «Избранное», очередь (переместить/удалить), shuffle, repeat
- Эквалайзер (полосы + пресеты + график), бас, виртуализатор, усиление громкости
- Скорость воспроизведения, таймер сна
- Открытие аудио из других приложений («Открыть с помощью»)
- Тема: системная светлая/тёмная + Material You; язык: системный (English / Русский)
